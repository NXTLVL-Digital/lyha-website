# Lynchburg Youth Hockey Association — Website

Static HTML site for the Lynchburg Youth Hockey Association (Hill City Coyotes).

## Pages

- `/` — Homepage
- `/mites/` — Mites (U8) division page
- `/faq/` — Sitewide FAQ
- `/admin/` — Sveltia CMS editor for Phase 1 board updates

## Hosting

Auto-deployed via Vercel on every push to `main`.

## Stack

Plain HTML/CSS/JS. No build step. Phase 1 now includes Sveltia CMS at `/admin` for board-member content editing before public launch.
